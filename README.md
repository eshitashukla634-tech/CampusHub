# 🚀 CampusHub

CampusHub is a smart campus management platform that we are building using Python.

The goal is to create a single platform where students, teachers, and administrators can manage important academic and campus activities.

## 🎯 Current Features

- Student Management
- Add Student
- View Students
- Update Student
- Delete Student
- SQLite Database
- Basic error handling
- Command-line interface

## 🛠️ Technologies

- Python
- SQLite
- SQL
- Git
- GitHub
